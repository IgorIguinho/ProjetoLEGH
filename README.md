# Projeto LEGH

Projeto open source desenvolvido em Unity para criação de jogos 2D.

## 🛠️ Stack

- **Unity** 2022.3.46f1
- **C#** (scripts)
- **Universal Render Pipeline (URP)**
- **Cinemachine** 2.10.3
- **Input System** 1.14.0
- **TextMeshPro** 3.0.6
- **Post Processing** 3.4.0
- **Visual Scripting** 1.9.4

## 📋 Requisitos

- Unity Hub instalado
- Unity Editor 2022.3.46f1
- Git

## 🚀 Como Rodar

1. Abra o projeto no Unity Hub:
   - Clique em "Add" e selecione a pasta do projeto
   - O Unity irá importar automaticamente os pacotes necessários

2. Abra a cena principal em `Assets/Scenes/`

3. Pressione Play no Unity Editor

## 🤝 Como Contribuir

Contribuições são bem-vindas! Siga estes passos:

1. Faça um **fork** do projeto
2. Crie uma **branch** para sua feature (`git checkout -b feature/MinhaFeature`)
3. Faça o **commit** das mudanças (`git commit -m 'Adiciona MinhaFeature'`)
4. Faça um **push** para a branch (`git push origin feature/MinhaFeature`)
5. Abra um **Pull Request**

### Diretrizes

- Descreva claramente o que sua contribuição faz
